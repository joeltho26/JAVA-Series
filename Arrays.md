# Arrays:

- once an array of primitive data type is created, we cannot modify it
- array of non-primitive data types can be modified which has a wrapper class like Integer, Character, StringBuilder, etc. except String data type which is a special non-primitive data type. 
- if not assigning values to arrays during declaration then default value for int => 0, boolean => false, class/object => null;
  ```
    int[] arrayInt = new int[5];
  
  // 5 => capacity and index starts from 0 to 4 
  ```
